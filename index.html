Turn on one-click downloads

Browsers can’t download from YouTube, so a small helper runs on your own computer. You set it up once.

  1. Install Python from python.org. On Windows, tick “Add Python to PATH”.
  2. On this project’s GitHub page choose Code, then Download ZIP, and unzip it.
  3. Windows: double-click helper/start.bat. Mac: open Terminal and run bash helper/start.command from the unzipped folder. Leave the window open.
  4. Reload this page. The status line near the top says “connected”.

Use Chrome, Edge or Firefox. Safari blocks pages from reaching the helper.
